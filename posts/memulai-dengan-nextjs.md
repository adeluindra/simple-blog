# Memulai dengan Next.js 15: Panduan Lengkap untuk Pemula

Next.js adalah framework React yang sangat populer untuk membangun aplikasi web modern. Dengan fitur-fitur seperti Server-Side Rendering (SSR), Static Site Generation (SSG), dan API Routes, Next.js menjadi pilihan utama banyak developer.

## Apa itu Next.js?

Next.js adalah framework React yang dikembangkan oleh Vercel. Framework ini menyediakan berbagai fitur out-of-the-box yang memudahkan developer dalam membangun aplikasi web yang cepat dan SEO-friendly.

## Fitur Utama Next.js 15

### 1. App Router
App Router adalah cara baru untuk mendefinisikan routing di Next.js. Dengan App Router, kita bisa membuat layout nested dan menggunakan Server Components secara default.

### 2. Server Components
Server Components memungkinkan kita untuk merender komponen di server, mengurangi bundle size JavaScript yang dikirim ke client.

### 3. Streaming
Next.js 15 mendukung streaming, yang memungkinkan bagian-bagian dari halaman untuk ditampilkan secara progresif.
